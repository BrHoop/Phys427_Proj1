HISTORY                                                                         
HISTORY Spextool FITS files contain an array of size                            
HISTORY [nwaves,4,norders*naps]. The ith image (array[*,*,i]) contains the      
HISTORY data for a single extraction aperture within an order such that,        
HISTORY lambda=array[*,0,i], flux=array[*,1,i],                                 
HISTORY uncertainty=array[*,2,i],flag=array[*,3,i].  The zeroth image           
HISTORY (array[*,*,0]) contains the data for the aperture in the order          
HISTORY closest to the bottom of the detector that is closest to the            
HISTORY bottom of the slit (i.e. also closest to the bottom of the              
HISTORY detector).  Moving up the detector, the FITS array is filled in         
HISTORY with subsequent extraction apertures.  If no orders have been           
HISTORY deselected in the extraction process, the contents of the ith           
HISTORY aperture in order j can be found as follows:                            
HISTORY lambda=array[*,0,{j-min(orders)}*naps + (i-1)],                         
HISTORY flux=array[*,1,{j-min(orders)}*naps + (i-1)],                           
HISTORY uncertainty=array[*,2,{j-min(orders)}*naps + (i-1)],                    
HISTORY flag=array[*,3,{j-min(orders)}*naps + (i-1)].
